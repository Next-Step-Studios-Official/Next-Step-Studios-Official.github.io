## 1. Scope

This overview describes the public Next Step Studios website and the small contact service that receives its form. It does not describe the Discord bot, which has its own [Security and Data Protection Overview](/policies/bot/security), or the internal systems of Discord, GitHub and the email provider.

It describes the site as it is built today. It is not a certification, an audit report or a guarantee.

## 2. How the site is built

The site is generated by Astro into plain HTML, CSS and a small amount of JavaScript. Every page is a pre-built file. There is no server-side application, no database, no login and no session for visitors.

The source is version-controlled, and the public build is produced from that source. Dependencies are declared in a lockfile so a build resolves the same versions rather than whatever happens to be newest.

## 3. Transport and hosting

The site is served over HTTPS by GitHub Pages. The hosting provider terminates TLS, serves the files and necessarily processes network requests. Its own logging and retention practices are set by GitHub, not by this website.

The studio does not control GitHub's infrastructure and does not claim to audit it.

## 4. What runs in the browser

The page loads its fonts, styles and scripts from this site. It does not load analytics, advertising, third-party embeds, third-party fonts or a client-side framework.

Three things use browser storage or make a separate request:

- the light/dark theme choice, stored in local storage under `nss-theme`;
- policy reading preferences, stored under `nss-reading-size` and `nss-reading-width`;
- the status page's read-only request to `raw.githubusercontent.com` for the bot's status file.

Step, the assistant, loads two static files from this site and answers in the browser. It sends no question to a server and keeps no conversation after the page is reloaded.

## 5. The contact form

The form posts to a small contact service operated for the studio. That service stores the message, a one-way hash of the network address for rate limiting, and the time it arrived. The raw network address is not stored with the message.

The private inbox sets one session cookie after the operator signs in. Visitors never receive that cookie. The inbox is not part of the static site and has no public registration.

## 6. Secrets and access

Secrets used by the contact service are kept outside the public repository and are not included in the browser build. The site itself needs no API key, database credential or user account to render.

Access to the private inbox is limited to the operator. The studio does not publish an administrative interface for the public site because the public site has no accounts or editable content.

## 7. What this overview does not claim

The studio does not claim:

- a formal security audit, penetration test or certification;
- compliance with a particular security standard or legal regime;
- that the site is impossible to compromise;
- that GitHub, Discord or the email provider are free of defects;
- a bug bounty, a response-time guarantee or payment for a report.

The site is small and static, which removes whole classes of risk. It does not remove every risk.

## 8. Reporting a security problem

Email [nextstepstudiosofficial.contact@gmail.com](mailto:nextstepstudiosofficial.contact@gmail.com) with the subject **Security** and enough detail to reproduce the issue. Include the page or endpoint, what you observed, and any steps needed to see it.

Please do not test against the live contact service, attempt to access another person's information, or post the issue publicly before it has been reviewed. There is no bounty programme, and none is implied. The studio will read the report, but no response time is promised.

The same contact address is published in the machine-readable [`security.txt`](/.well-known/security.txt).

## 9. Changes

This overview is versioned with the rest of the website documents. A material change to how the site is built, served or secured is recorded as a new version, and the previous text remains available in the version history.
