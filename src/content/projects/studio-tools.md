## The idea

Most of the work behind the bot is repetitive: generating documents, checking that a
build is consistent, turning one source of truth into several formats. A studio that
does that work often ends up with small tools worth keeping.

## The honest position

Nothing here has been started. This entry exists so the category is visible on the
projects page and so a future tool has somewhere to land. If no tool is ever worth
publishing, this entry will be removed rather than filled with invented plans.

## What would count as progress

A tool becomes a real project entry when it has a name, a working version and someone
other than its author can run it. Until all three are true, it stays Planned.
