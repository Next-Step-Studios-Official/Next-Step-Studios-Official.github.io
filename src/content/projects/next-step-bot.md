## What it is

Next Step Bot is the Discord bot the Studio builds for its own private Discord server.
It is internal server tooling, not a product offered for installation elsewhere.

Its purpose is to handle the routine operations of a single community: letting people
apply for staff and other roles, running support conversations as tickets, publishing
announcements, and giving the server's administration a consistent set of tools.

## Where it actually stands

The Bot is in development, tested on the Operator's own machine against one server.
Different parts of it are at different stages, and this page reflects that rather than
presenting the Bot as a finished service.

| Area | Status |
| --- | --- |
| Core bot operation and commands | Implemented; verification ongoing |
| Applications and staff review | Implemented; verification ongoing |
| Support tickets | Implemented; transcripts unverified |
| Announcements | Partially implemented |
| Configuration and administration | Implemented; verification ongoing |
| Logging and diagnostics | Implemented; verification ongoing |
| Moderation and infractions | Planned |
| Ban appeals | Planned |

"Implemented; verification ongoing" means the feature exists and runs, but its full
behaviour — storage, access, cleanup, failure handling — has not been confirmed end to end.
"Planned" means it does not exist as a working feature yet.

## What it is not

- **Not publicly installable.** It is built for one server and is not offered to
  unrelated servers.
- **Not a finished product.** There are no release versions, no public sign-up and no
  support commitments.
- **Not verified as production-ready.** Production readiness is tracked separately by the
  Operator, and some items on that list are outstanding.
