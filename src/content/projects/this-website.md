## What it is

This is the studio's public reference: the projects, the Discord bot's commands and modules,
the policy documents, the downloads and the devlog. Every page is generated at build time into
plain HTML, CSS and a small amount of JavaScript. There is no server-side application, no
database and no visitor account.

The site is served by GitHub Pages. Its source is version-controlled, and the documents and
downloads are generated from that source rather than edited by hand in several places.

## What is real

- The pages are pre-built and publicly readable.
- The policy documents are published in two separate sets, with Markdown, plain-text, PDF and
  print editions.
- The search index and the Step assistant run locally in the browser.
- The status page reads a public JSON feed and falls back to a build-time copy.
- There are no analytics, advertising, third-party fonts or tracking cookies.

Those are properties of the build, not promises about a future service.

## What is still moving

The site is in development because it is still being revised: copy, layout, exports and the
document set all change as the studio's work becomes clearer. Nothing about the current build
is frozen, and no uptime or release schedule is promised.

The policy documents are a mix of current descriptions and drafts awaiting review. The
[policy hub](/policies) labels each one rather than treating the whole set as finished.
