## What is decided

Games are the direction. The studio was founded to make them, and the Discord bot is the work
that funds the time to learn how. The first game is an original project being written from
scratch in **C#** — the code is being built for this project rather than assembled from a
ready-made game template.

## What “C#” means

**C# is pronounced “C-sharp”.** The `#` is the musical sharp sign, not a hashtag, so it is not
“C hashtag”. C# is a general-purpose programming language developed by Microsoft and used for
games, desktop software and web services. Writing the game “from scratch” means the game's
code is being written for this project rather than starting from a ready-made game kit.

## What is still being worked out

The title, genre, art direction, platforms and release date are still open. The pictures on
this page are early visual studies, not screenshots of a playable build. They show the visual
language being explored, not features that are finished.

## When this page changes

The status moves to **Prototype** only when something runnable exists — a build that can be
played, even badly. Until then, “In development” is the accurate word. New pictures will be
added here as they are ready.
